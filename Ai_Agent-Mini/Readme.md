# AI Agent Mini

A small educational AI agent built with **Python** and the **OpenAI API**.

This project demonstrates how an AI model can use custom tools to perform tasks and interact with files.

## Features

- 💬 AI chat assistant
- 🧮 Calculator tool
- 🌤️ Current weather tool
- 💱 Currency exchange tool
- 🌐 AI-powered static website generation
- 📁 File and directory management
- 🔒 Safe file-path handling

## Tech Stack

- Python
- OpenAI API
- WeatherAPI
- Frankfurter API

## What You Can Learn

This project is useful for learning:

- OpenAI function/tool calling
- AI agent loops
- API integration
- JSON handling
- File operations in Python
- Building simple AI agents

## Setup

Install dependencies:

```bash
pip install openai
```

Set your API keys as environment variables:

```bash
export OPENAI_API_KEY="your_api_key"
export WEATHER_API_KEY="your_weather_api_key"
```

Then run the Python file:

```bash
python ai_agent-mini.py
```

> **Note:** This project is created for educational purposes to understand the basic concepts behind AI agents and tool calling.
